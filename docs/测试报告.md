# 拾见校园测试报告

测试日期：2026-10-10。当前版本包含 **27 项单元测试 + 14 项接口与集成测试**。

## 1. 工具与复现

使用 Node.js 内置 `node:test`、`node:assert/strict` 和 `fetch`，没有 Jest / Vitest 等额外依赖。本地执行环境为 Windows、Node v24.19.0。

```bash
npm test
node --test --experimental-test-coverage tests/core.test.js tests/storage.test.js tests/server.test.js
```

测试入口为 `tests` 中的三个文件；`test` 定义用例，`assert.equal` / `deepEqual` 检查结果，`assert.throws` / `rejects` 检查失败路径。接口测试通过 `before` 启动临时端口、`after` 关闭服务，测试数据写入独立临时目录。

学习入口：[Node 官方测试文档](https://nodejs.org/api/test.html)。

## 2. 白盒设计方法

先读 `validatePost`、`searchPosts`、`changeStatus` 与本机存储的实际控制分支，再为每条主要成功 / 失败路径构造输入。测试同时采用边界值和等价类：例如标题最大长度 40，分别测试 40 和 41；时间选择无法解析、过去和未来；修改状态选择本人、他人、未登录与缺失记录。

本文没有把“用例通过”等同于“所有分支已覆盖”。账户数量上限、真实磁盘写入失败、页面异步事件和图片解码等仍需要额外环境或浏览器验证。
