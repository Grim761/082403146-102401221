## 实现顺序

1. 提取校验、搜索、状态更新等业务函数，建立离线存储。
2. 实现线索墙、详情、发布、我的发布及交互反馈。
3. 实现共享服务、账号和发布者权限；保持离线 HTML 可运行。
4. 编写单元测试、接口测试，并使用 Chrome 验证页面。
5. 整理 README、图示、截图、开发记录和博文草稿。
