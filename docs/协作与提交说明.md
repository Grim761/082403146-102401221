## 结对协作者的 fork / PR 操作

1. 用自己的 GitHub 账号打开主仓库，点击 **Fork → Create fork**。
2. 克隆自己的 fork，在新分支中完成实际修改。建议复核搜索的组合条件、时间边界或存储事务异常，选择发现的具体问题补充测试或修复。

```bash
git clone https://github.com/coderbrain404/shijian-campus.git
cd shijian-campus
git switch -c test/storage-boundaries
npm test
```

3. 阅读现有代码，执行程序，记录实际检查的结果。修改后再次运行测试；提交信息应说明改了什么。

```bash
git add tests docs
git commit -m "test: cover storage failure and recovery boundaries"
git push -u origin test/storage-boundaries
```

4. 在自己的 fork 点击 **Contribute → Open pull request**，目标为 `Grim761/shijian-campus:main`。PR 写清真实改动、测试命令和结果。
5. 主仓库维护者复核差异和测试结果后合并。双方博文分别放主仓库 / fork / PR 链接和实际协作截图。
