## 已修复的问题

### 发布成功后旧表单又成为草稿

发布成功先清空草稿，再跳转详情；但 hashchange 原先还会对旧表单执行保存，因此旧内容会再次出现。修改为成功发布时设置一次性跳过标志，普通离开表单仍保存文字。浏览器验证：发布后再打开发布页，名称为空，没有恢复旧草稿。

### 快速换图可能出现旧图片覆盖新图片

文件读取和图片压缩是异步操作，仅判断当前路由不能区分同一路由上的两次选图。增加图片处理序号，只有最新操作可以更新预览和按钮状态。处理期间禁用发布，避免发送尚未压缩完的图片。

### 程序刷新后的数据和归属

旧原型仅有内存数组。新实现保存稳定的本机身份和记录；共享模式从会话取发布者 ID 并在服务端执行同一状态规则。本机存储和 API 测试分别检查重载、账号越权和磁盘数据。

## 验证边界

当前浏览器自动化连接为 Edge。连接中尚无 Chrome；自动化浏览器禁止访问 `file://`。因此不得把直接双击 HTML 或 Chrome 操作写成已验证的事实。已完成的浏览器检查使用本地 HTTP 服务；课程要求的 Chrome 和文件方式保留独立的手动复核项。
